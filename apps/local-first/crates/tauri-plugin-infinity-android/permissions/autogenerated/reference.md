## Default Permission

Enables counting contacts and probing Shizuku.

#### This default permission set includes the following:

- `allow-count-contacts`
- `allow-shizuku-status`
- `allow-whatsapp-web-probe`
- `allow-whatsapp-pair`
- `allow-whatsapp-state`
- `allow-whatsapp-read`
- `allow-whatsapp-send`
- `allow-start-foreground-service`
- `allow-stop-foreground-service`
